# Tavares Racing Configuration Tool

Configurador dos pedais **TR-Pro** da Tavares Racing.

Cada versão fica em [Releases](../../releases) com:

- o instalador para Windows (`TavaresRacing_Setup_vX.Y.Z.exe`);
- o código-fonte daquela versão (GPL v3);
- o `latest.json`, que o próprio programa lê para avisar quando há versão nova.

A atualização pelo programa troca só o aplicativo do PC. O firmware da placa do pedal não é alterado.
